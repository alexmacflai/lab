# Humanise copy

Applies two editing passes to new or changed copy without flattening each prototype's voice.

## When to use

- Creating or changing text people read, including copy embedded in code, accessible labels and prototype documentation, even when the request is framed as implementation.
- Not for determining AI authorship or rewriting exact supplied wording, approved text or attributed quotations without authorisation. Reviewing copy can result in no changes.

## Inputs

- Text, its audience and purpose, actual interface behaviour, and the prototype's brief, README or approved examples where available.

## Steps

1. Read [copy rules](../../../knowledge/copywriting/copy-rules.md), [voice and tone](../../../knowledge/copywriting/voice-and-tone.md) and [editing.md](editing.md). Use the relevant prototype's context; ask only when missing information would change the edit.
2. Identify facts, uncertainty, action semantics, quotations and voice traits to protect. For new copy, retain the first draft as the comparison point; for existing copy, retain the original.
3. Perform the broad-pattern pass, retaining its attributable changes.
4. Perform the focused-pattern pass separately. Leave effective, distinctive wording alone.
5. Compare each pass with the original or first draft for semantic drift, lost tone, invented facts and changed promises. Check interface wording against its implementation; flag unresolved claims instead of inventing specifics.
6. Keep each pass reviewable. For routine implementation, use a concise before/after comparison and separate pass summaries in the task response or existing review record; do not create archive documents for individual labels. For substantial prose, retain intermediate versions or attributable diffs. State when a pass made no changes.

## Done when

- Both passes are attributable, and facts, functional meaning and the piece's supported tone are preserved.
- Uncertainty is flagged. Agent editing does not imply human editorial review; offer read-aloud review for prominent lines where useful.
