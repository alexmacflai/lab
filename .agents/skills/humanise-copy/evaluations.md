# Behaviour evaluations

Run each request in a fresh context with the skill and raw evidence only; withhold the good-result description. These cases are evaluation criteria, not completed test results.

## Copy embedded in code

- Request: Add an archive button and confirmation to this prototype.
- Evidence: Archiving hides a recording and can be undone. Draft HTML: `<button>Unlock a cleaner library</button>`. Draft JavaScript string: `Gone forever. A fresh start.`
- Good result: Applies copy guidance without an explicit editing request; labels the archive action clearly, preserves reversibility and provides attributable broad/focused changes without creating copy archives.

## Clean copy and accessible labels

- Request: Check this button, error and icon label.
- Evidence: `Save recording`; `Upload failed. Try again.`; `aria-label="Close settings"`. Saving, retrying and closing work as described.
- Good result: Leaves all three unchanged; records no-change passes rather than manufacturing defects or personality.

## Unknown claim

- Request: Humanise “Our tool significantly improves efficiency.”
- Evidence: No measurements or further product details.
- Good result: Flags the unsupported claim or makes a supported minimal edit; invents no statistic, capability or personal experience.

## Different prototype tones

- Request: Review these two prototype introductions and their controls.
- Evidence: A playful drawing toy has the approved introduction “Five pens. No adult supervision.” and a working `Pause` control. A quiet poetry piece has the approved line “the room keeps its rain” and a working `Start` control.
- Good result: Preserves both introductions, their different tones and clear controls; adds no shared catchphrase, portfolio first person or explanatory interpretation.

## Preserve voice and actions

- Request: Humanise this supplied draft in two passes.
- Evidence: “Well, that was a fucking excellent gig. Maybe our best. Archive this recording to hide it from your library; you can restore it later.” Archiving is reversible.
- Good result: Preserves bluntness, humour, uncertainty and reversible meaning; shows original/broad/focused changes separately, including no-change outcomes.

## Exact wording and quotations

- Request: Implement the approved label “Let's go!” exactly and display Sam's quote “Its made our work clearer.”
- Evidence: The wording is approved and attributed as shown.
- Good result: Reproduces both exactly, flags any suspected typo separately, and performs no unsolicited rewrite or punctuation ban.

## Nearby unrelated request

- Request: Fix pointer tracking; leave text unchanged.
- Evidence: A canvas coordinate bug; no copy changes needed.
- Good result: Fixes the requested behaviour without editing copy or starting an unrelated humanising task.
