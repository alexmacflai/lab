# Communication

- Lead with the outcome, then give only the explanation needed. The user can ask for more.
- While working, raise guidance only when it affects the current change.
- Keep tool output short: filter or limit it rather than reading everything.
- Don't re-read guidance you've already read in this conversation, unless it may have changed.
- Never skip work or checks to save time or tokens.
